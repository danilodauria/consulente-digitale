Privacy e sicurezza

Un programma che può aggiornare e modificare il computer deve essere più sicuro di un programma qualsiasi. Ecco tutte le difese e l'elenco completo di ciò che esce dal computer.

Le difese

  • Solo questo computer: il motore ascolta su 127.0.0.1; rifiuta richieste con un nome di computer (Host) o un'origine diversi dai propri, così una pagina web aperta nel browser non può comandarlo.
  • Lista chiusa di azioni: nessuna API esegue comandi liberi; solo le {{N_AZIONI}} azioni del catalogo, con parametri in lista bianca (capitolo 2).
  • Codice di sessione nuovo a ogni avvio, obbligatorio per avviare o fermare un'azione e per spegnere il programma.
  • Permessi del sistema: le modifiche passano sempre da UAC, polkit o dalla password del Mac. Il programma non conserva e non vede mai le vostre password.
  • Download verificati: Python per Windows e Ollama sono controllati con la firma digitale del produttore; tutto il resto arriva da gestori ufficiali che verificano da soli (Windows Update, winget, apt/dnf, Flathub, fwupd, Apple, Homebrew).
  • File di lavoro temporanei: gli script delle azioni vengono scritti nella cartella lavori dei vostri dati, leggibili solo da voi su Linux e Mac, e cancellati dopo un giorno.
  • Nessuna libreria da Internet: le pagine non caricano nulla dal web (niente caratteri, script o statistiche esterne).

Controllare che i file siano originali

Ogni versione ha il file SHA256SUMS con le «impronte digitali» dei pacchetti. Se un solo byte cambia, l'impronta cambia.

# Windows (PowerShell)
Get-FileHash .\ConsulenteDigitale-Setup-{{VERSIONE}}.exe -Algorithm SHA256
# Linux, nella cartella dei file
sha256sum -c SHA256SUMS --ignore-missing
# macOS
shasum -a 256 ConsulenteDigitale-{{VERSIONE}}-macOS.zip

Confrontate il risultato con la riga corrispondente di SHA256SUMS, pubblicato sulla pagina ufficiale del progetto.

Tornare indietro

Ogni modifica si può annullare. Il modo più semplice è il punto di ripristino (Windows) o l'istantanea (Linux con Timeshift, Mac con Time Machine) creati prima delle azioni con rischio medio e dal pulsante «Crea un punto di ripristino».

🪟 Windows

  1. Punto di ripristino: Start → scrivete rstrui → Invio → scegliete il punto «Consulente Digitale…» → Avanti → Fine. Il computer si riavvia com'era. I vostri documenti non vengono toccati. (Il Consulente attiva la protezione del sistema sul disco C: se era spenta e permette di creare punti anche a distanza di pochi minuti.)
  2. Copie del registro: prima di «Più privacy», «Ottimizzazione completa» e «Modalità PC vecchio» le chiavi modificate vengono salvate in %APPDATA%\ConsulenteDigitale\copie\<azione>-<data>\. Un doppio clic su un file .reg rimette i valori di prima.
  3. Singole impostazioni: piano energetico in Pannello di controllo → Opzioni risparmio energia; effetti visivi in sysdm.cpl → Avanzate → Prestazioni; servizio «Windows Search» in services.msc.

🐧 Linux

  • Timeshift (o Snapper): aprite il programma, scegliete l'istantanea «Consulente Digitale» → Ripristina.
  • Senza Timeshift il Consulente salva /etc e l'elenco dei pacchetti in /var/backups/consulente-digitale/. Per ripristinare un file: sudo tar -xzf etc-DATA.tar.gz -C / etc/NOMEFILE.
  • Memoria: sudo rm /etc/sysctl.d/90-consulente-digitale.conf e riavvio. zram: sudo apt remove zram-tools.
  • Avvio: sudo systemctl enable NetworkManager-wait-online.service. Animazioni GNOME: gsettings set org.gnome.desktop.interface enable-animations true. Indicizzazione: balooctl enable (KDE) o systemctl --user unmask tracker-miner-fs-3.service (GNOME).

🍎 macOS

  • L'istantanea locale di Time Machine resta circa 24 ore: Time Machine → scegliete la data, oppure dal ripristino di macOS.
  • Modalità PC vecchio: Impostazioni di Sistema → Accessibilità → Schermo, togliete «Riduci movimento» e «Riduci trasparenza»; per il Dock: defaults delete com.apple.dock launchanim; killall Dock.
  • Privacy: Impostazioni di Sistema → Privacy e sicurezza → Pubblicità di Apple.
Cosa non si annullaGli aggiornamenti installati di solito non si tolgono (e non si dovrebbe: sono di sicurezza), salvo da Windows Update → Cronologia → Disinstalla aggiornamenti. I file eliminati dalla pulizia (temporanei, cache) non tornano, ma non servono: i programmi li ricreano.

Il primo posto dove guardare è il registro del motore, server.log nella cartella dei dati (capitolo 38), e il registro dell'azione nella console.

Aggiungere un'azione

  1. Scrivete lo script per ogni sistema in src/azioni/<sistema>/ usando le funzioni comuni: passo/Passo, voce/Voce, info/Info, ok, nota, attenzione. In PowerShell non usate mai exit: in caso di errore $global:CD_CODICE = 1 (o Errore "testo").
  2. Aggiungete la voce in AZIONI (cd_azioni.py): id, gruppo, icona, rischio, titolo, descrizione e, per ogni sistema, file, admin e finestra. Se serve un parametro, aggiungete la sua regola in valida_parametro: mai testo libero.
  3. Collegate un pulsante (CD.esegui("id")) e, se utile, una frase in neura.js.
  4. Collaudate: shellcheck, controlla_powershell.py, test_ui.py, e su un vero Windows e un vero Mac.
  5. Rigenerate il vademecum: il catalogo e i passi degli script si aggiornano da soli.

Pubblicare una nuova versione su GitHub

Il sito danilodauria.github.io/consulente-digitale contiene la pagina dei download e il file aggiornamenti.json letto da «Scarica gli aggiornamenti» (capitolo 27). L'indirizzo si cambia in un solo file, rilascio.conf.

  1. Aumentate il numero in VERSION e scrivete le novità in cima a docs/novita.json.
  2. Rifate foto e vademecum (tools/schermate-manuale.py, tools/genera-vademecum.py), poi ./build.sh: i pacchetti finiscono in dist/.
  3. python3 tools/prepara-pubblicazione.py: crea la cartella sito/ con index.html, aggiornamenti.json (versione, novità, indirizzi e impronte SHA-256), i file in scarica/ e SHA256SUMS.
  4. Con GitHub Desktop sul repository consulente-digitale: scrivete il riepilogo (es. «Versione 1.1.0»), Commit to main, Push origin.
  5. Il workflow .github/workflows/pubblica-sito.yml pubblica la cartella sito/ su GitHub Pages (la prima volta: Settings → Pages → Source: GitHub Actions).
  6. Da quel momento ogni Consulente Digitale installato, premendo «Controlla aggiornamenti», trova la nuova versione.
Regole del progettoMai modifiche senza clic · fonti ufficiali · niente telemetria · italiano semplice · ogni stampa con il piè di pagina di autore e licenza · numeri di versione mai riusati (correzione X.Y.Z+1, novità X.Y+1.0).
